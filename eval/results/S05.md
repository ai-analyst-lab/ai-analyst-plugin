## Routing verdict (which descriptions compete, and who wins)

For the bare prompt "compare the last two quarters":
- **Winner (correct): analyst-core + question-framing.** Both explicitly claim the bare verb "compare"; context-compare's description claims only ablation phrasings and self-labels "Advanced"; compare-datasets scopes itself to cross-dataset asks. At the description layer the routing is unambiguous — **no hijack occurs as written.**
- **Residual hijack surface (real, but one layer down):**
  1. context-compare's BODY claims the `/compare` namespace: "## Invocation: `/compare \"<the question>\" --with <setup_dir>`" and H1 "Skill: Compare (with and without)" — while its frontmatter trigger says `/context-compare` (and reliability's SKILL.md also calls it "/context-compare"). A user typing the natural shorthand `/compare Q1 vs Q2` lands in the ablation harness by the body's own contract. Frontmatter and body disagree about the skill's own name.
  2. If context-compare ever does fire, its code cannot run: Steps 1-3 import `aievals.adapters.ai_analyst_plus` and `aievals.harness.comparison`, and **no aievals package ships anywhere in the plugin** (grep confirms the only mention is context-compare's own SKILL.md; the skill has no scripts/ dir). The "with/without" run would die on ImportError.

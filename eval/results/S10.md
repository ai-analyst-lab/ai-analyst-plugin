Diagnostic output (script stdout):


**Skewness handling: correct.** The pipeline's decision points caught the skew exactly as designed — mean/median ratio 10.0 (>1.3 threshold), CV 13.1 (>1.5 heavy-tail flag), top-1% share 71.6% triggering the power-law check. Normality rejected loudly; log-normal checked and also rejected (the column is a plan-tier mixture with a whale tail, so log(x) stays non-normal). Identification landed at "heavy-tailed right-skewed; moderate/low confidence between lognormal-mixture and power-law tail; report both" — which is what the skill's own confidence rubric prescribes for this case.

**Test-selection guidance: produced.** Report recommends median/IQR/MAD over mean/SD for description, Mann-Whitney U (or bootstrapped difference-in-means / trimmed means) for two-group comparison, quantile or log-link GLM regression, bootstrap CIs; A/B section warns that a t-test on raw mrr is whale-dominated (one enterprise account moves the mean more than thousands of starters), recommends CUPED/winsorization or rank-based tests and much larger n. This is the correct playbook for the planted shape.

**Step 3 could not be followed as written.** `.knowledge/references/statistical-distributions-guide.md` does not exist: not in the plugin (searched the whole tree), not in the `.knowledge` contract (`docs/KNOWLEDGE.md` defines no `references/` directory), and not created by knowledge-bootstrap or connect-data. The skill's Reference section describes it as a "1,700+ line guide" and Rule 5 forbids substituting model memory — yet memory is the only available path. Distribution identification and test recommendations were therefore improvised (correctly, but in direct violation of the skill's own Rule 5).

**Description scoping (the routing question): good.** The description opens "Single-column distribution deep-dive" and every trigger phrase is column-scoped ("profile this column", "what distribution is this"). The neighboring skills complete the fence: `data-profiling`'s description says "for one column use distribution-profiler", and `data-map` claims the dataset-wide asks ("tell me about this data", "give me an overview") while explicitly excluding deep profiles. A dataset-wide ask has no trigger match here. No defect.

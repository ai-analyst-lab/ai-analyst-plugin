Only three skills (question-framing, visualization-patterns, stakeholder-communication) check learnings content. A clearly-framed, chart-less lookup ("what was July net revenue?") skips question-framing per analyst-core ("a clearly framed request can skip straight to work") and produces no chart — on that path **no instruction ever surfaces the EUR rule**. This run honored the rule because the deliverable happened to route through a checking skill.
2. **Note (not classed):** A taught rule with a missing parameter ("EUR" but no FX rate, none stored anywhere) forces the honoring session to either ask or assume. Handled here by a labeled assumption in Checks; the learning-entry format has no field for parameters like a conversion rate.

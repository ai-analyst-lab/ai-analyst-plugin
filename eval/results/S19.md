## Defects found

1. **AMBIGUOUS** — Vocabulary mismatch between skill text and bundled script: the brief skill
   mandates the flag set **VIABLE / LONG / IMPRACTICAL** (VIABLE <4wk, LONG 4-8wk, IMPRACTICAL
   >8wk), while the bundled `duration_estimate()` returns **VIABLE / MARGINAL / NOT_VIABLE**
   (<=28d / <=56d / >56d). The bands align but the labels don't; an agent must silently map
   MARGINAL→LONG and NOT_VIABLE→IMPRACTICAL. Same-plugin components disagree on the controlled
   vocabulary. (The experiment SKILL.md power mode also branches on "NOT_VIABLE", so the
   brief skill is the odd one out.)
2. **WRONG-INSTRUCTION** (minor, latent) — experiment-brief SKILL.md references skills by the
   path convention `.claude/skills/metric-spec/skill.md` and `.claude/skills/guardrails/skill.md`;
   in this plugin the skills live at `skills/{name}/SKILL.md`. The referenced skills exist, so
   this is a stale path style rather than a missing piece; it did not block execution.

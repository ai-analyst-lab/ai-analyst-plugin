## Setup

Horizon: 2 quarters = 6 months.

## What actually happened (evidence: `s21_output.txt`, `s21_fix_output.txt`)

1. **Seasonality NOT detected by the shipped script.** `detect_seasonality(s)` returned
   `has_seasonality: false, dominant_period: null` on raw AND detrended series, despite a
   lag-12 ACF of +0.849 (2x the 0.408 threshold). Root cause (verified in code + output): with
   n=24, `effective_max = n//2 = 12` lags, and the peak scan `for i in range(1, len(acf)-1)`
   can only crown an interior lag (2..11) — **lag 12 is the last element and is structurally
   unreachable**. Annual seasonality on monthly data — the most common business forecasting
   shape — cannot be detected with fewer than ~26 monthly points, and the failure is silent.
2. **Skill-flow consequence:** followed literally ("If seasonality detected" gates the seasonal
   methods), the session would have shipped a non-seasonal drift/SES forecast that misses the
   planted Nov-Dec peak entirely. Avoided only by improvising a direct lag-12 ACF check.
3. **`seasonal_naive` silently used a nonsense cycle:** its internal `_infer_seasonal_cycle`
   also failed, then fell back to the hardcoded default **7** — a weekly default that assumes
   daily grain — producing a meaningless "7-month cycle" forecast on monthly data
   (`s21_output.txt`: "repeating the last 7-period cycle").
4. **`exponential_smoothing` cannot forecast:** returns keys `[alpha, beta, fitted, mae, mse,
   residuals, seasonal_period, interpretation]` — **no forecast values, no level/trend/seasonal
   state to extrapolate from**. Step 3 instructs using it as a forecasting method; as shipped it
   is fit-only. Holt-Winters (period=12, n=24 = the exact minimum) fit but likewise yields no
   future values, with in-sample MSE (645M) worse than drift (503M).
5. **The skill's MSE selection rule picks a method that can't forecast:** in-sample MSE
   comparison crowned simple exp smoothing (alpha=0.99, MSE 0.05M — a one-step-ahead
   near-random-walk fit) over multi-step baselines. Apples-to-oranges comparison, and the
   "winner" has no forecast output.
6. **Delivered forecast (improvised around 3-5):** seasonal naive on the true 12-month cycle +
   drift (last year's month + 12x monthly trend step): Sep $581K → Dec peak $692K → Feb $694K;
   **Q1 (Sep-Nov) $1.83M, Q2 (Dec-Feb) $2.06M**. Residual σ = $9,987; ±1σ and ±2σ bands
   produced. Holdout check (fit 18, test 6) reported honestly: naive-last won the flat holdout
   window (1,012M vs 1,631M MSE), flagged with the caveat that no non-seasonal method can carry
   the Q4 peak. Assumptions stated ("past patterns continue; external factors not modeled").
7. **Chart per conventions: YES** (`working/forecast_revenue_2026-08-25.png`, visually
   verified): warm `#F7F6F2` ground, no top/right spines, no grid, Action Amber actuals,

## Defects found

1. **BROKEN-SCRIPT** — `detect_seasonality()` structurally cannot return the last computable
   lag as the dominant period (interior-peak scan), so annual seasonality on monthly series
   with n < ~26 is silently missed even at ACF +0.85. Wrong result, no error raised.
2. **BROKEN-SCRIPT** — `naive_forecast(method='seasonal_naive')` falls back to a hardcoded
   7-period cycle (daily-grain assumption) when inference fails; on monthly data it fabricates
   a 7-month "season" with no warning.
3. **MISSING-PIECE** — `exponential_smoothing()` returns fitted values only; there is no
   function in the bundled library that produces future values from a fitted smoothing model,
   yet Steps 3-5 of the skill treat it as a forecast generator and candidate "best method."
4. **WRONG-INSTRUCTION** — "Compare MSE across methods. Select the best-fit method" compares
   one-step in-sample fit against multi-step baselines; followed literally it selects a
   non-forecasting model (SES, alpha→1) and contradicts Rule 3's own naive-baseline intent.
5. **AMBIGUOUS** (minor) — data-sufficiency thresholds are written in points but exampled in
   days ("60+ for quarterly projections"); for monthly grain that reads as demanding 5 years,
   which cannot be the intent. Judged 24 points / 2 full cycles sufficient.

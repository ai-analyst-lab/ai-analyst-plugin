# S25 — chart standards: visualization-patterns produces the SWD chart

**Round:** 1 (R7 runner) | **Date:** 2026-08-25 | **Grade:** B | **Verdict:** PASS

## What the skill promised
`visualization-patterns/SKILL.md`:
- "Apply whenever generating ANY chart ... Enforces Storytelling with Data: gray first, max 2
  colors + gray, action titles, direct labels, decluttered design" (frontmatter)
- Step 1: "Before writing ANY charting code, set the SWD base style yourself" — rcParams block
  with `COLORS["action"] = "#D97706"` (Action Amber focus)
- Step 2 highlight-bar: "Horizontal bars by default (`ax.barh`), sorted by value ... every bar is
  `gray200` except the highlighted category, which gets `action` amber ... Hide the value axis
  entirely ... direct value labels at the end of each bar"
- Action title: "bold, left-aligned, fontsize ~17 ... `y=1.12` (subtitle at `y=1.06`)"
- Theme merge line: "When no theme or palette is set, use the default styling without asking;
  offer palette options only when the user asks about themes or colors."

## What actually happened
Prompt: "make me a chart of conversion by channel" against `funnel_users.csv` (8,000 users,
visit->signup->activate->pay). Script `s25_chart.py` was written by following Steps 1-3 literally
and run for real; PNG rendered and visually verified.

- Evidence: `scratchpad/eval-r7/s25_chart.py`, `scratchpad/eval-r7/paid_conversion_channel_bar.png`,
  sidecar `paid_conversion_channel_bar.md`
- Rendered chart checks (verified by viewing the PNG): amber (#D97706) on the referral bar only,
  all other bars gray200; horizontal, sorted; value axis fully hidden (no naked axes; no x
  ticks/spine); direct % labels at bar ends; action title ("Referral converts visitors to paid at
  5.6x the paid-search rate") left-aligned at y=1.12; insight subtitle at y=1.06; source line;
  warm off-white background.
- Numbers verified from data: referral 14.6% (141/966) vs paid_search 2.6% (54/2,061) = 5.57x;
  referral 12.1% of traffic, 25.5% of payers.
- Theme-picker merge behavior: no theme was set; the default styling was applied with no
  interruption and no palette question — behaved exactly as the merge line specifies. WORKS.

## Defects
1. **WRONG-INSTRUCTION** — Step 3 save example is a mangled merge artifact:
   `fig.savefig("the working folder (final charts sit next to the brief; intermediates go in working/)conversion_by_device.png", ...)`.
   Followed literally this produces a garbage filename. Recovered via the naming-convention line
   directly below (`{metric}_{dimension}_{chart_type}.png`), so friction was minor.
2. **WRONG-INSTRUCTION** — action-title code line is not valid Python as printed:
   `ax.set_title(..., loc="left", y=1.12 (subtitle at y=1.06; do not use pad, it collides with subtitles))`
   — prose merged inside the call's parentheses. Intent recoverable, copy-paste breaks.
3. **CONTRADICTION** — "Default Theme: Minimal" says the minimal theme has "Action Blue accent
   (#2563EB)" and "The SWD base style (Step 1) is the minimal theme", but Step 1's focus color is
   Action Amber #D97706, and the `MINIMAL_THEME` dict further down uses background #FFFFFF vs the
   base style's #F7F6F2. Two incompatible definitions of the default palette; the agent must guess.
   Resolved by following Step 1 (it is marked "DO THIS FIRST" and governs Steps 1-3 charts), which
   is also what the amber-focus standard implies is intended.

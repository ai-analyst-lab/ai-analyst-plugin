## Defects
1. **AMBIGUOUS** — scoring denominator: "Total Possible: 85 points (70 if
   cross-verification/reproducibility not available)" defines only the both-unavailable case.
   Here reproducibility WAS available and cross-verification was not; the applicable max (75)
   had to be inferred. Two agents could reasonably score 70/75=93 or 70/85=82 — a full letter
   grade apart (A vs B). The skill should state per-bonus exclusion explicitly.
2. **MISSING-PIECE** — the cross-verification bonus activates "if cross-verification results
   exist (from `working/cross_verification_*.yaml`)", but grep shows NOTHING in the plugin ever
   produces such files (the string appears only in triangulation itself). As shipped, the
   10-point bonus layer is unreachable — a dangling reference to an absent producer.
3. (Not a defect, an observation: `run_structural_checks` silently ignores unknown config keys
   — a first attempt with a wrong key reported 2/2 instead of erroring. The documented config in
   data-quality-check SKILL.md is correct and recovered it; a strict-keys guard would make
   misuse visible.)

## Grade rationale
Both modes produced their promised outputs, deterministically computed, with the bundled script
reused as instructed. Friction: the scoring denominator required an interpretation that can move
the final grade, and one bonus layer is dead code as shipped. B.
